# Романтичный квест-приглашение 💌

Небольшое одностраничное React-приложение: квест из 2 вопросов-загадок (шифр и сложная задачка), после которых появляется главный вопрос — приглашение на свидание.

## Технологии

- React 18
- Vite

## Установка и запуск

```bash
npm install
npm run dev
```

После запуска открой в браузере `http://localhost:5173`.

## Структура вопросов

Все вопросы и ответы лежат в массиве `QUESTIONS` в файле `src/App.jsx`:

```js
const QUESTIONS = [
  {
    id: 1,
    title: "Расшифруй шифр",
    prompt: "Тут текст загадки с шифром.",
    answers: ["правильный ответ"],
    hint: "Необязательная подсказка."
  },
  // ...
];
```

- **title** — короткий заголовок вопроса.
- **prompt** — текст загадки / вопроса.
- **answers** — массив возможных правильных ответов (сравнение идёт без учёта регистра и пробелов по краям). Можно также использовать одно поле `answer` со строкой, если вариантов только один.
- **hint** — необязательная подсказка (можно оставить пустой строкой).

Чтобы изменить квест, просто подставь свои вопросы и ответы.

## Как это работает

- Сначала показывается экран-вступление с кнопкой «Начать квест».
- Затем по одному показываются 2 вопроса (шифр и задачка).
- Если ответ вводится верно, пользователь переходит к следующему вопросу.
- После 2-го правильного ответа появляется экран с вопросом «Согласна?», а затем финальный экран с поздравлением и фейерверками.
